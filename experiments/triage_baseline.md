# ベースライン対比（単一LLM 1回 vs 多段パイプライン）

> ベースライン=gpt-4oに1回で全トリアージを構造化出力（分解/RAG/決定論/IME/precedentなし）。
> パイプライン=advisory(素判定)。同一ゴールド・単一実行。`triage_baseline.py` で再現。

> **注（2026-10-01）**: MedDRA の行は、正解データが**本物のMedDRAコード**を持っていた時点の測定。ベースラインはモデルの記憶からMedDRAコードを答え、それを本物のコードと照合した。その後、MedDRA を同梱しないためにコードを架空の `DEMO-xxxx` に置き換えた（[ADR 0014](../docs/adr/0014-meddra-not-bundled.md)）。そのため、この行の29%は現在のリポジトリでは再現できない（再実行するとベースラインは原理的に0%になる）。パイプラインの100%は、辞書と正解データが一緒に置き換わっているため再現できる。他の行は影響を受けない。

| 指標 | ベースライン(1回LLM) | パイプライン(多段) |
|---|---|---|
| MedDRA PT 完全一致 | 29% (6/21) | 100% (23/23) |
| 重篤度 一致 | 100% (21/21) | 91% (21/23) |
| 　└ 過小コール | 0 | 0 |
| 因果 一致 | 100% (21/21) | 100% (23/23) |
| 　└ 過小コール | 0 | 0 |
| 既知/未知 一致 | 71% (15/21) | 100% (23/23) |
| 　└ 過小コール | 3 | 0 |
| 抽出 recall | 91% (21/23) | 100% (23/23) |
| 余分抽出 | 0 | 3 |

## 解釈

- **MedDRA**: ベースラインは辞書拘束が無く、PTコードを幻覚・不一致しやすい（パイプラインは
  辞書＋ハイブリッド検索で拘束）。既知/未知も、ベースラインは添付文書RAGが無く当て推量。
- **過小コール**: パイプラインは決定論OR＋安全側で過小を抑える設計。ベースラインの過小の有無が
  安全性の差を示す。限界: 小規模・単一実行・gold自作（[[triage_eval.md]] 限界節と同じ）。
