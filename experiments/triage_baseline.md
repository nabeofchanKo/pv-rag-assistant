# ベースライン対比（単一LLM 1回 vs 多段パイプライン）

> ベースライン=gpt-4oに1回で全トリアージを構造化出力（分解/RAG/決定論/IME/precedentなし）。
> パイプライン=advisory(素判定)。同一ゴールド・単一実行。`triage_baseline.py` で再現。

| 指標 | ベースライン(1回LLM) | パイプライン(多段) |
|---|---|---|
| MedDRA PT 完全一致 | 32% (10/31) | 100% (31/31) |
| 重篤度 一致 | 100% (31/31) | 94% (29/31) |
| 　└ 過小コール | 0 | 0 |
| 因果 一致 | 100% (31/31) | 100% (31/31) |
| 　└ 過小コール | 0 | 0 |
| 既知/未知 一致 | 43% (9/21) | 100% (21/21) |
| 　└ 過小コール | 1 | 0 |
| 抽出 recall | 100% (31/31) | 100% (31/31) |
| 余分抽出 | 0 | 5 |

## 解釈

- **MedDRA**: ベースラインは辞書拘束が無く、PTコードを幻覚・不一致しやすい（パイプラインは
  辞書＋ハイブリッド検索で拘束）。既知/未知も、ベースラインは添付文書RAGが無く当て推量。
- **過小コール**: パイプラインは決定論OR＋安全側で過小を抑える設計。ベースラインの過小の有無が
  安全性の差を示す。限界: 小規模・単一実行・gold自作（[[triage_eval.md]] 限界節と同じ）。
