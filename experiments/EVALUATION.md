# 評価まとめ（こう評価した）

PVトリアージ支援パイプラインを、**安全加重（過小コール最優先）**の視点で評価した記録。
数値を誇張せず、限界と「示せたこと／示せていないこと」を明確に分ける方針で書いている。

- **評価対象**: 取り込み → 自社品ゲート → 6軸トリアージ（抽出・MedDRA・重篤度・因果・既知未知）→ 過去判例(precedent) → 過去データ反映(influence) → HITL。
- **標本**: 合成ICSR 7症例。うち in-scope 5症例・23事象を精度採点、**自社品なし2症例は Phase 4g でハードゲート**（評価対象外）。難症例2件（婉曲表現の重篤+未知／抽出精度）を含む。
- **ゴールド**: Claude起案 → **PV専門家レビュー反映**（expert-reviewed。QTc間隔の延長/腎機能の悪化を追加、報告事象名の verbatim 化、自社品なしの out-of-scope 化）。ただし**完全ブラインドの独立ゴールドではない**ため、アノテータ間一致（天井）は未測定。
- **再現**: `experiments/scripts/*.py` を project venv で実行。temperature=0でもLLMは完全決定的でないため単一実行スナップショット。
- **注**: 下表の E1/E2/E3 個別レポートは**ゴールド更新（v2）＋ゲート導入の前**のスナップショット。所見の向きは不変だが、厳密な数値整合には再実行が要る（[triage_eval.md](triage_eval.md) は v2 で更新済み）。

## 示せたこと（頑健）
1. **安全側インバリアントが頑健に成立**：過小コール0が、本評価・K=3全run・ホールドアウト・難症例（婉曲表現の重篤+未知）の**すべて**で維持。influenceの**格下げ0**も全所で成立。PVトリアージの最重要要件（見落とさない）を満たす。
2. **多段＋RAG＋辞書の価値が定量化**：単一LLMに対し MedDRA +68pt（32→100）、既知/未知 +57pt（43→100）。既知/未知ではベースラインが安全側の過小を1件出したのに対しパイプラインは0＝**RAGが安全性にも寄与**。
3. **判定の再現性が高い**：run間の全一致率 ≥97%。抽出はナラティブ由来事象で軽微に揺れる（正直な弱点）。
4. **スコープ判定が正しく効く**：自社品なし2症例を**ハードゲートで正しく評価対象外**（2/2）＝評価不要な症例に計算・誤判定を出さない。

## 示せていないこと（正直に）
1. **「フィードバックで精度が上がる」は未実証**。ホールドアウトでは未知症例に対し precedent は何も上書きせず（0件）。素判定の過小が既に~0で「直すべき誤り」が乏しいため。本評価(seed入り)で見えた1件の安全側変化は**seed依存のアーティファクト**で、ホールドアウトがそれを暴いた。→ 学習効果は「素判定が誤る難症例をより多く含む集合」でこそ検証すべき。
2. **重篤度・因果は単一LLMが競合**。多段は重篤度で安全側に過大（94% vs 100%）。過大は過小より許容だが、コスト（アラート疲れ）は別途評価が要る。
3. **標本が小規模・ゴールドは expert-reviewed だが完全独立でない**。in-scope 5症例23事象は高分散、100%は「誤りなし」であって精度100%ではない。ゴールドはClaude起案をPV専門家がレビュー・修正したもの（QTc/腎機能追加、verbatim、out-of-scope化などの実質修正が入った）が、**完全ブラインドの2人目アノテータではない**ため、アノテータ間一致（天井）は未測定。

## 総合評価（私の見立て）
> **小規模・自作ゴールド上の回帰ベースラインとして、(1)安全側インバリアント（過小0・格下げ0）が本評価・反復・ホールドアウトで頑健に成立し、(2)多段＋RAG＋辞書がMedDRA/既知未知で単一LLMを大きく上回ることを定量化した。** 一方で「学習が精度を上げる」は**この規模・一貫性では実証できず**、seed依存の見かけの効果をホールドアウトが正しく否定した。エビデンスとしては入口だが、**測定の作法と安全性の裏づけ**は形になっている。

## 完全な検証への道筋（次段）
- **E4 一部実施（expert-reviewed）**。残：**完全ブラインドの2人目アノテータ**でアノテータ間一致（天井）を数値化。
- **E1/E2/E3 の v2 再実行**：確定ゴールド＋ゲートで数値を整合（所見の向きは不変見込み）。
- **規模拡大**：素判定が誤る難症例を増やし、ホールドアウトで学習効果に「信号」を出す。
- **N回×多数**：点推定→CI。
- **過大コストの評価**：安全側過大の実務コスト（余分な expedited 報告・レビュー負荷）を定量化。
