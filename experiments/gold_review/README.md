# ゴールド独立レビュー（E4）— 記入手順

目的：システムの出力とも私（Claude）の起案ゴールドとも独立に、あなた（PV専門家）が
各事象の「正解」を付ける。これで (a) システム精度を独立ゴールドで測り直し、(b) あなたの
判断と私の起案の**アノテータ間一致**（＝天井）を測る。現状の「自作ゴールド＝循環」を解く最重要ピース。

## 独立性を保つための順番（重要）
1. 先に **`data/sample_reports/case_00X.txt` の本文だけ**を読む。
2. `worksheet.md` の空欄を**本文だけで**埋める。
3. 埋め終わるまで **`data/gold/`（私の起案）とシステム出力・評価レポートは開かない**（アンカリング防止）。
4. 既知/未知の判断時のみ、対象薬の**架空添付文書**を参照：`data/drug_labels/drugx_label.md` / `drugy_label.md` / `drugz_label.md`。

## 各列の基準
- **MedDRA PT**：割り当てるPT名（コードでも可）。辞書は `data/meddra_sample/meddra_pt.csv` を参照可。
- **重篤度（企業・ICH E2A）**：`重篤` / `非重篤` / `要確認`。
  - 重篤＝死亡・生命を脅かす・入院/入院延長・障害・先天異常・医学的に重要 のいずれかに該当。
  - **重症度≠重篤性**（強い症状でも上記に当たらなければ非重篤）。
  - **その事象自身**に帰属する事実で判定（他事象の入院・処置を流用しない）。
  - 疑いのみで確信が持てない＝`要確認`（安全側）。
- **因果（保守的・時間的）**：`否定できない` / `否定できる` / `評価不能`。
  - 投与後に発現＝既定で `否定できない`（因果の証明ではなくトリアージ）。
  - `否定できる` は明確な時間的不整合のみ（投与開始前の発現、または中止後で残存/遅発効果も否定できる場合）。
  - 日付不足で時間関係を確立できない＝`評価不能`。
- **既知/未知（薬剤別・添付文書基準）**：`既知` / `未知` / `要確認` / `判定不能`。
  - **提供した架空添付文書に照らして**判断（実世界知識ではなく）。記載あり（直接一致/同義）＝既知。
    読み替え・機序のみ＝要確認（安全側）。記載なし＝未知。
  - **DrugA（case_004）・DrugB（case_005）は自社品でない＝対象外（空欄）**。
- **追加/削除**：本文にあるのに表に無い事象は「追加」、誤抽出は「削除」を各症例の欄に。
- **コメント**：迷った所・議論所の判断根拠を一言。

迷った所は「要確認」で構いません（それも情報）。
